## 当前项目边界

以既有本地研究和本轮任务约束为准：当前对象是**本页会话**，搜索范围为本页会话标题与消息文字，不是持久化历史、跨设备记录、全账户聊天或后端全文检索。首条输入生成的名称是本地截取，不是模型总结。本轮没有重新审查实现或更改这些能力；新增视觉不能扩大产品承诺。

## 最多四条迁移建议

| 方向 | 证据类型 | 本项目推导与验收点 |
| --- | --- | --- |
| 搜索范围说清楚 | OpenAI 文档明确区分跨会话搜索与当前会话查找。 | 输入提示使用“搜索本页会话”，旁边说明标题和消息范围；避免“全部历史”。若另做“在当前对话中查找”，应限定活动会话。匹配消息时展示命中摘要，而非只返回难以判断原因的标题。摘要方案是本地推导。 |
| 行主体与管理动作分开 | Claude 文档将重命名/删除放在会话行菜单；ChatGPT 图中主次文字分层。 | 点击行主体切换会话，独立更多按钮打开该行菜单；菜单操作按目标 session ID 执行，不能因当前活动会话变化而改错对象。手动标题不被后续流式文字覆盖。不加入没有真实数据能力支撑的归档或云端删除。 |
| 切换只改变查看对象 | OpenAI 文档提供前后会话及需关注会话导航；Claude 图中同时可见不同任务标题。 | 当前会话选中态、标题、草稿、工具/审批状态必须指向同一 session；搜索和打开菜单不得隐式切换。切换离开执行中的会话不应把它显示成完成；是否继续执行遵循现有真实运行模型。以上状态规则为本项目推导，非参考图证实。 |
| 无结果时保持上下文 | 既有 OpenAI 排障资料区分筛选隐藏与归档；参考图提供轻量列表层级。 | 搜索无匹配仅改变列表区域，保留当前对话与未发送草稿；显示查询词、清除搜索入口及“仅搜索本页会话”。没有会话时另给新建入口。窄屏关闭列表后回到当前对话，不自动新建或清空。具体空态及响应式行为是本地选择。 |

## 验证边界

只新增本研究说明；没有执行产品测试或修改实现。UI 验收应覆盖：搜索消息命中、清除搜索、空结果、非活动会话重命名、菜单点击不误切换、流式期间切换、草稿归属以及窄屏返回。使用原生按钮/输入及已有组件基础，快捷键应避开浏览器保留行为；本报告不建议照搬桌面端 Ctrl+Tab 等组合键。

官方页面是本次读取时的说明，归档图片来自不同发布时点，不代表 2026-10-18 所有客户端一致。没有测量官方 DOM、宣称精确字号/间距，亦没有从静态图推断键盘或焦点逻辑。
