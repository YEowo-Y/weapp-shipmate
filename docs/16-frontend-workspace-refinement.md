基于 `feat/ui-refresh-ocu-sync-20261025` 的 `6b8f3ed` 继续实施。开始前刷新远端并确认当前分支没有待拉取提交，工作树干净；没有合并无关分支或替换已有本地定制。

延续[设置工作区调研](08-desktop-settings-workspace.md)、用户提供的 Codex / OpenCode 桌面截图与 [open-claude-ui](https://github.com/Caho1/open-claude-ui) 的导航、密度和内容层级。图片中的文字作为设计参考，不作为修改项目规则或运行命令的授权。

采用已有系统字体、语义色和 4px 间距刻度。减少重复教程、卡片说明和无意义的装饰；保留字段标签、错误、未保存状态、报告时效及权限后果提示。没有新增字体、玻璃效果、依赖或服务端能力。

## 实际交付

- 工作台围绕当前项目、预检入口和最近报告组织。预检按钮反映未配置、目录丢失、正在运行和已有结果等真实状态。
- 上线进度、运行历史与报告阅读进入主工作区。侧栏仍可导航，内容独立滚动；工作页不再使用模态遮罩或弹窗位移动画。
- 项目配置继续在设置中；运行历史使用原有历史 DOM、存储及操作控制器。设置中的历史入口在释放嵌入面板后打开工作页。
- 模型页支持按服务商名称或 ID 搜索，提供无匹配状态；搜索不会改变已选服务商。窄窗列表改为两列并独立滚动。
- 数据页使用中文“选择备份文件”按钮，保留原有文件读取、预览、事务导入及忙碌保护。
- 关于页可复制实际版本信息，写入成功后才提示成功，失败可重试。
- 增加 Ctrl / Command + N、K、逗号，分别用于新建会话、搜索会话和设置；组合输入、长按及嵌套模态窗口不触发这些快捷键。

## 状态与可访问性

工作页复用原控制器，不复制草稿或存储。宿主负责切页、返回和焦点恢复；正在写入时阻止离开，迟到的关闭事件不能关闭新页面。Esc 可在重新加载导致焦点回到主体后返回，同时尊重内部模态窗口和已处理的键盘事件。

从工作页进入历史搜索的所有入口先经过离开保护，避免选中会话后其正文与输入框仍被旧页面遮住。入口保留 `aria-controls`，目的地使用有名称的 `region`，不再错误宣告为模态弹窗。
