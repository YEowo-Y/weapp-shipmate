# 会话管理、搜索和任务切换验收

日期：2026-10-18。范围为 `desktop/design-previews`；本轮没有将预览迁入 Tauri 主应用，没有部署或增加依赖。

## 结果

- 桌面侧栏的新建、搜索和范围说明保持可见，仅会话列表滚动。标题/摘要为 14px / 12px，摘要最多展示两行，当前行的更多操作可见；沿用现有主题变量、图标与菜单组件。
- 搜索明确标为“搜索本页会话”。消息命中片段保留完整查询词和两侧上下文；可访问描述关联该片段，清除后移除关联。视觉上长摘要仍截断，完整内容保留在描述中。
- 切换或新建会话保存并恢复未发送内容、选区起止、选择方向和 textarea 内部滚动位置。选择当前会话只聚焦输入区，不重置或中止执行。
- 移动导航从已搬移的真实控件读取当前会话名，修复旧标题；Escape 尊重中文组合输入与已处理事件。先清搜索，再关闭导航；弹窗取消返回仍可见的行操作。
- 重命名仍复用原生 dialog 和既有校验；操作非当前会话不会更改当前任务，筛选后消失的行将焦点归还搜索框。

## 启动与限制

启动：`node desktop/design-previews/_serve.mjs`，打开 `http://127.0.0.1:5501/chat-full.html`。本轮无需新增环境变量；现有 5501 预览服务保留。

会话与搜索仍限本页内存，刷新清空；没有持久历史、云端全文搜索或后台多会话执行。本次执行测试使用明确标记的本地演示，没有调用真实模型、读取项目文件或执行外部操作。中文组合输入保护有单元测试，本轮未使用真实系统输入法或屏幕阅读器验收。窄屏是浏览器视口模拟，没有真机测试。
