## 最小修改与验收

1. 输入区只展示当前真实可运行的“本地演示”，模型弹出菜单锚定按钮，列出当前执行来源与“管理模型服务”入口。删除无效推理档位，不把权限或工作方式混作模型。
2. 模型设置复用 Cherry 官方实际截图中的“设置导航 / 可搜索提供方列表 / 配置详情”布局。提供方切换联动地址、凭据要求和模型草稿列表；Ollama 无云密钥要求。外部提供方保持未连接，配置格式检查不冒充网络验证。
3. 当前无凭据后端：密钥只在当前输入框临时存在，切换/关闭清除，不进入 URL、storage、日志或模型菜单。非密钥草稿仅当前页面保留，避免在纯原型引入存储协议。默认执行来源仍为本地演示；不把填写配置视为连接成功。
4. 结果采用“结论 / 需处理项 / 下一步”层级。工具摘要先呈现，参数和原始结果折叠；依据可展开，审批独立且状态驱动。保留流式文字渐变、停止、失败、重试及编辑会话连续性。
5. 未接入的其他设置标明预览并禁用，取消虚假的执行与安全保证；真实可用的主题、页面导航和搜索继续工作。
