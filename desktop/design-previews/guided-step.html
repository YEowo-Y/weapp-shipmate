配置服务器域名白名单

需你本人 · 工具不代点

小程序请求的后端域名必须先在后台登记，否则真机请求会被拦截。下面使用保留的示例域名，未扫描你的代码。实际配置时请使用自己的服务域名。

已勾选 0 / 5 步

  1. 登录微信公众平台

    用注册时的邮箱 + 密码登录 mp.weixin.qq.com。

  2. 进入「开发设置」

    左侧菜单：开发管理 → 开发设置。打开官网后按此路径进入：

    打开微信公众平台
  3. 3

    填写「request 合法域名」

    示例域名 · 不可用于真实后台配置

    https://api.shipmate.example

    找到「服务器域名」区块，在 request 合法域名 一栏填写你自己的服务地址。下图仅展示字段位置：

    mp.weixin.qq.com · 开发管理 · 开发设置

    开发设置 › 服务器域名

    request 合法域名
