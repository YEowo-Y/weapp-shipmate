# 会话持久化与历史搜索实施合同

2026-10-18；直接执行，原生子代理负责独立切片，不启用 OMX runtime。现有预览为原生 ESM；保留现有消息协议、原生菜单/dialog、主题与浏览器验收工具，零新增依赖。

## 可观察验收

1. 本浏览器同源/项目的会话、标题、消息、选定模型元数据、引用、编辑草稿、选区、阅读位置刷新后恢复；新建和继续发送不产生 ID 冲突。
2. 历史搜索查已保存和当前会话标题/消息，不检索未发送草稿或伪称跨设备搜索。搜索不改变当前会话，点击命中可打开对应记录。
3. 输入与消息变化即时排队保存；只有 IndexedDB 事务完成后显示“已保存”。串行合并待写快照，离页前补充保存；未保存时使用浏览器原生离页保护。
4. 采用版本化白名单快照和事务 revision CAS；多窗口旧副本不能覆盖新数据。失败保留当前内存内容与已有记录，提供重试/备份，读取失败不以默认示例覆盖数据库。
5. 恢复 working/streaming 为已中断，保留部分输出，停止动态进度；审批恢复为历史过期状态，不自动恢复任何执行授权或请求。
6. 存档不含连接凭据、OAuth 状态、DOM/控制器/Blob URL；结构化结果复用现有校验，非法版本/损坏记录不静默清空。
7. 浏览器验收刷新、重开页面、恢复后发送、搜索、切换、运行中刷新、窄屏；储存失败和冲突以单元/浏览器故障场景覆盖。

## 边界与方案

IndexedDB 为本地历史事实来源；按项目保存一份原子快照，事务内读取版本并比较，提交完成才确认成功。不同浏览器、协议、主机、端口不共享；无云端同步、后台多会话执行或自动续跑承诺。浏览器清理/隐私模式/配额限制仍可能影响保留，提供可下载的本地 JSON 备份。

先补回归测试，再修改存储边界与调用点；独立存储模块负责验证/事务，页面负责状态提示与重试，现有会话运行时仅补 ID 唯一性及必要草稿变化通知。改动保持可逆，不重置已有脏工作区。
