# 设置与业务弹窗标准化计划

日期：2026-10-20；续接 component-workbench-review.md。

## 边界与修改意图

保留 Vanilla TypeScript / Vite / Tauri、现有模型连接和存档接口。复用已固定的 Web Awesome Core 3.14.0 操作按钮、图标和主题；不引入第二套 UI 库。原生 dialog 继续提供顶层遮罩、Escape、inert 与表单语义；密码和搜索使用原生输入，避免改动凭据清理、IME 和搜索协议。统一视觉与业务动作，删除重复的按钮/弹窗样式，不把已有预览设置伪装成真实能力。

本轮覆盖三处：共享业务弹窗（清单配置、确认、文件/命令）、共享会话弹窗（历史、重命名、存档恢复）及浏览器设置和正式桌面模型连接。菜单行、模型列表、导航保留原生语义控件，动作按钮统一使用开源组件。依据真实 Codex/Claude/Cherry 图片与官方组件 API，保留来源和版本边界。

## 验收与质量依据

风险 high：共享交互与凭据表单展示；不改授权或模型协议。命令发现自 package.json、desktop/package.json、scripts/desktop-native-e2e.mjs 与既有测试。先执行相关基线；随后执行测试、lint、TypeScript/Vite、Tauri 构建和 Windows 端到端检查。运行浏览器 320/768/1280px、浅深色、键盘/焦点、取消、关闭、输入错误恢复，记录实际截图。模型流回归使用隔离协议测试替身，真实云端推理不作本轮通过声明。

必须保持：关闭和提交清理密钥；空输入不提交；忙碌状态不重复请求；Escape/取消回到可见触发者；历史搜索与草稿不丢失；工具提交参数与原有接口一致；窄屏不横向溢出；所有 icon-only 操作有可访问名称。

## 写入职责

- 主执行者：components/ui-kit.js/css 的操作按钮桥接、统一 dialog/form 样式、ui.js 业务弹窗、会话弹窗、共享焦点检查及浏览器/原生验收集成。
- 设置执行者：settings.html/js/css 及设置专属测试，复用桥接，不修改共享实现。
- 桌面执行者：src/model-connection.ts、对应模型 CSS 和测试，不修改共享实现。
- 只读研究与独立复核：来源/API 核实、最终变更检查。

回退限于上述文件的本轮差异；无迁移、删除、账号变更或发布。本轮以本地功能验收为交付边界，无 CI/发布就绪声明。
