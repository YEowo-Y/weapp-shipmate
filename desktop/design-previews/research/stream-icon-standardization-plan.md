# 流式输出与图标标准化

日期：2026-10-13。范围：chat-full、main-four-region、component-showcase 及共享预览组件；保留原生 JavaScript 技术栈、现有事件与本地演示边界。

执行中收到的新截图补充验收：正文与工具行按发生顺序穿插，而非把所有工具堆在回复末尾。使用现有本地控制器的明确工具开始/结果事件构造展示 parts；不模拟不存在的子 Agent、浏览器搜索或文件写入。工具完成和整条回复完成分别表达。

## 清理意图与验收

1. 流式、完成、停止使用同一安全段落渲染，已有段落节点不随 token 重建；不实现自制 Markdown 解析器。
2. 消息 working / streaming / complete / stopped / error 与运行事件一致，首字前有准备反馈，终态清除忙碌语义；仅状态变化通过现有 live region 宣告。
3. 停止保留输出并允许重新生成；不可重试错误不提示可重试；计划创建失败有独立运行身份，不污染历史。
4. 图标复用官方 Lucide 有限 SVG 子集并保留许可证，统一描边、尺寸、装饰语义；删除字符图标、重复 SVG 创建函数与发送伪元素。无文字按钮的中文名称、提示、发送/停止状态同步。
5. 保持 IME、Enter/Shift+Enter、工具展开、阅读锚点、审批边界与菜单焦点行为。桌面/移动端、深浅主题、键盘可用。

## 执行中文字渐变补充

用户追加要求：执行中展示文字渐变。最小范围为共享 message.css：工具 running 的标题与状态、消息准备/生成提示应用中性色扫光；正文及所有终态保持原样。沿用主题文字色，不增加依赖或 JS 计时器。仅在允许动态效果且支持文字背景裁切时启用，高对比/减少动态效果保留原文字。先观察现状，再做 CSS 解析、既有状态测试与实际深浅主题执行/终态检查，记录截图和独立只读审查。

后续调整：渐变启用时移除同位置旋转圈。只在现有渐变条件块内隐藏 running 工具图标和 working/streaming 提示图标，并停止其动画；终态图标以及不启用渐变的降级模式沿用现状。验证渐变和图标互斥、终态图标正常，避免新增运行状态或渲染逻辑。
