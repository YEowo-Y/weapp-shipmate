模型与密钥

自带 LLM key（BYO key）。船友不托管模型、不代付算力，密钥与成本都在你这边——这也是"自建 agent + 纯公益"能成立的前提。

确定性预检无需 key 也能用；key 只解锁 AI 辅助（变更影响分析 · 问诊访谈 · 拒因编排…）。
已连接

密钥存于系统钥匙串（macOS Keychain / Windows 凭据管理器），永不写入 localStorage、环境变量或命令行，永不上传。

密钥怎么被保护（broker 模式）

[WebView] invoke("chat", {messages}) ← 载荷里没有 key [Rust 核] 1. 钥匙串取 key 2. 拼 Authorization 3. 调 LLM 4. 只回 {content} [WebView] 只拿到 {content} ← key 永不过 IPC / 日志 / 后端
启用 AI 辅助
关闭后仅保留 46 条规则的本地确定性预检

外观

engineered calm：中性暖灰为底，只有赭橙 + 绿/黄/红四色承载意义。字体本地打包，离线可用、无 CDN。

字体：Inter（界面）+ JetBrains Mono（终端 / 规则 id / 路径 / 已核验输出）——mono 是"可信工程工具"的廉价信号，也把已核验规则和 AI 散文在视觉上分开。

工程体检 · 能力开关

每个开关 = 一个 MCP 工具的增减。关闭即该工具从 agent 的 tools/list 移除——agent 看不到、调不了，比塞 prompt 可靠。需 BYO-key 启用。

隐私与安全

默认最严，与"不做担保"同灶——源码不出本机，agent 永不替你提交官方后台。

预检 local-only不可关
源码只在本机扫描，绝不上传
忽略密钥 / 证照 / 私有配置文件
扫描默认跳过 .env、密钥、证照文件
报告脱敏
只报文件 + 键名 / 域名，绝不回显密钥值
子进程 env 清洗
env_clear + 白名单，key 绝不进任何 MCP server
第三方 MCP 插件P3 · 暂未开放
需 M1–M9 安全基线，留作后期差异化弹药
