# 桌面 agent 模式、预览与体验版上传：实施验收

这是后续工单的验收要求，未实现或未通过的操作不开放。授权对象和操作范围以[总体方案 §4.3–4.6、§5.1](../25-vertical-agent-shell-plan.md)与[治理承诺](../../GOVERNANCE.md)为准。测试用临时项目、替身服务和无效的标记字符串，不使用真实账号密钥。

## 从项目读取到发送给模型（T08、功能 6）

| 边界 | 在哪一层执行 | 如何验证 |
|---|---|---|
| 模式与接收方 | 项目默认摘要模式，读项目与分享摘要分别授权；开启 agent 前显示项目及自选服务商。退出模式或切换项目、服务商时撤销旧授权并丢弃待发工具结果。 | 使用记录请求的替身服务：默认无源文件内容；显式同意后只有已授权文件可发；读完后关闭或切换接收方，没有旧文件被继续发送。|
| 私有文件与路径 | T08 给读、搜、改一份本机拒绝清单；功能 6 从宿主选定的根目录解析目标，逐项检查路径和链接，不让模型指定根目录。拒绝项在打开文件前拦下。 | 用同一组普通文件、忽略文件、根外目标和 junction 分别尝试读、搜、改；只允许根内普通文件。用文件访问替身核对：被拒绝项从未打开，搜索结果无匹配片段。|
| 多文件修改与撤销 | 先记录各文件检查点和原哈希；提交前校验未变，采用原子替换；批次失败或中断须恢复整批原状。恢复前比对原哈希和本批写后哈希；遇到外部改动先停下，保留检查点并交由用户处理。撤销前核对写后哈希，发现外部更改即停。命令生成的产物不在检查点范围，执行前向用户说明。 | 在单文件替换前后分别中断，重启时只能看到完整原文或完整新文。两文件批次第二项写入失败，或在第一项替换后终止进程：重启恢复后无混合版本。分别在恢复前、撤销前从外部修改一项，两种情形均保留外部内容，不改其他文件，显示冲突。|
| 命令与权限 | 在本机按操作和参数结构选择已允许的可执行文件，传参数数组，不经 shell。授权关联项目与操作，文件内容、工具结果、云资源名称及截图/日志仅是数据。 | 未列命令和未列参数在创建进程前失败；各类输入即便要求提权、登录、预览或上传，模式和命令记录不变。|
| 数据保存与密钥 | agent 工具不得读取、保存、回显项目密钥；拒绝内容和疑似秘密的值不进入模型请求、工具结果、日志、对话和备份。对话与工具结果的持久化只在本机。 | 用不含真实凭据的标记检查上述出口；拒绝提示只给文件和键名。用户已选择的模型服务商处理本次请求，不代表船友运行存储服务。|

## 开发者工具（功能 7、7b、12）

- **连接检测（功能 7 的公测部分、功能 12 复用）**：仅检查安装、服务端口、登录状态。通过测试替身分别返回未安装、端口关闭、未登录与已就绪，核对各状态及下一步；不启动编译或登录。遇到要求 CLI 令牌的配置就停在手动操作提示，不读令牌文件，不索取、不保存令牌。登录由人完成；登录二维码只在本机临时展示，离开视图即清除，在网络请求、对话、日志、临时文件和备份里均找不到。
- **模拟器走查（功能 7）**：本机命令表分别授权开项目/编译与构建 npm；每次走查要用户确认。走查工具只接受打开页面、按选择器点击、输入、滚动、截模拟器图和读日志的固定参数。以替身记录方法调用：拒绝 `evaluate`、`exposeFunction`、`callWxMethod`、`mockWxMethod`、对应插件方法、`remote` 和 `testAccounts`，以及任何未列方法。不得提供命令透传、通用屏幕抓取或桌面自动点击。截图和日志在摘要模式只供用户查看；只有 agent 模式可发送给选定服务商。
- **走查端口生命周期（功能 7）**：启动前确认指定回环端口未监听，走查期间确认仅本机地址监听；正常结束、取消和异常时都调用 `disconnect()`，保留项目窗口，不能用 `close()`。对同一端口用全新连接验证不可连接，并核对监听已消失。仅凭客户端断开不算通过；没有经真实开发者工具验证的关闭办法前不开放走查。
- **预览（功能 7）与体验版上传（7b）**：本机 UI 的逐次点击是这两项操作的唯一入口，模型、公开 MCP、后台重试不能触发。首次预览先说明代码包传给微信；上传还须打开默认关闭的开关，且每次确认本机开发者工具执行、代码只送微信、仅生成体验版而不提审发布。用命令替身验证：取消、无点击、关闭上传开关均为零次派发；每次确认最多派发一次；自动应用修改权限不跳过确认。用户在微信后台自行提审和发布。

## 域名与云（功能 10、11）

- **功能 10**：预检只列候选域名，用户逐次点击才可进行 TLS 握手和证书检查；不发 HTTP 请求、不跟随跳转。连接目标限定解析并核准的公网地址；回环、内网、不可判明及混合结果不连接并说明原因。用解析器与连接替身核对未点击或非公网结果的连接次数为零；公网测试记录只有握手。输出带依据的「满足 / 不满足 / 无法判断」，不能由此推导审核结论。
- **功能 11，CloudBase**：按项目显式启用经批准的可选固定版本，仅用本地 stdio，启动时关闭遥测；无自定义 MCP、无远端端点。逐个审核工具及返回字段，只允许所需资源元数据。用含新增工具、部署方法、数据库记录读取、SQL 查询以及能返回临时密钥的 `auth` 的替身清单验证：模型既看不到也不能调用这些工具。登录只由用户在 CloudBase 设备码或浏览器界面完成，不将敏感认证结果交给模型或写入船友存储；元数据只在获准的 agent 模式分享。
- **功能 11，旧 CLI**：匹配三个完整操作 `cloud env list`、`cloud functions list`、`cloud functions info`，分别校验参数。用命令替身核对列表/详情返回所需字段；部署、增量部署、其他子命令和任意额外参数在进程创建前被拒绝。开发者工具不能连接时展示手动核对路径，不索取凭据。
