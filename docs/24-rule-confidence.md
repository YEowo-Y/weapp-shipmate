## 含义与兼容性

- JSON 条目可包含 `confidence: "high" | "medium" | "low"`；Markdown 和桌面显示高 / 中 / 低，明确这是规则维护者对规则准确性的把握，不是命中概率或过审保证。
- 预检、上线清单（包括条件自查）和拒因查询保留规则原值。流程导航、合成检查和旧报告缺值时不补造评级；桌面拒绝显式非法值。
- 既有低置信规则仅通过显式包含草案选项进入报告。本轮没有提高规则评级，也没有实时核验官方政策。
- 修复交接 JSON 往返保留该字段。导入会话及其派生清单、交接 Markdown 标注“备份记录的规则置信度”，仍显示外部内容未在本机核验。直接打开外部交接文件时保留已有外部来源警告，字段不能证明来自本机当前规则库。
- `confidence` 与拒因的 `relevance` 独立：前者描述规则维护者的把握，后者描述反馈文本的匹配相关性。
