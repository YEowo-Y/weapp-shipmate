# P1：Windows 随包运行时与原生边界

日期：2026-10-22。对应[总体计划 P1](../../../.omx/plans/project-completion-plan-20261022.md)和[修改前执行方案](../../../.omx/plans/p1-runtime-execution.md)。本轮推进 P1，未进入 P2 数据迁移；保留全部既有工作。风险 high，涉及打包、进程、文件访问和 IPC 权限。

## 已落地的实现

- Windows x64 内置 Node 24.22.1。首次准备从官方源下载并校验锁定 SHA-256，保留完整许可；后续可复用校验后的缓存。显式复制 CLI、规则、broker、共享契约以及 js-yaml/argparse 生产依赖，79 个文件记入摘要清单。准备失败不覆盖上一份完整资源包。
- CLI 与模型桥共用 `resource_dir/runtime` 解析；删除 PATH Node 和编译期源码定位，不用源码回退掩盖缺资源。路径规范化后必须处于运行时目录内。摘要清单用于构建/安装完整性验收，不冒称运行期防篡改或代码签名。
- 本机工具由 `runId` 关联，单次运行、30 秒超时、stdout/stderr 各 2 MiB 限额。取消、超时和关闭执行 kill/wait；启动前预留编号，避免点击停止早于 worker 启动的竞态。失败与预检发现问题分开：check 的 0/2、guide 的 0 是有效完成，其余退出不能用 stdout 冒充成功。
- 错误保留退出码和至多 1024 字符的 stderr 摘要，移除控制/双向格式字符，明确标注截断。目录不存在、无权限、非目录、缺资源、取消、超时、输出超限分别反馈。
- 工具栏复用现有按钮和状态区，补充“停止执行”；等待执行与停止确认都结束后才能重跑。停止或失败保留上次成功报告，并注明它不是本次结果。无新组件框架。
- 所有自定义原生命令登记进 Tauri ACL，只允许本地 main 窗口；Rust 再校验窗口来源。CSP 不允许任意脚本、框架页或直接向模型供应商发请求，样式保留现有 Lit/Floating UI 所需 inline style。Opener 仅 HTTP(S)，不开放文件、任意程序、mailto/tel；正常引用链接不限制域名。
- Release 清除 Node preload、路径与 TLS 环境覆盖。Debug broker 仅为既有原生协议测试保留 NODE_OPTIONS；CLI 始终清除。模型服务启动/写入失败清理子进程和待响应请求，下一次操作可重建服务。

## 参考与采用理由

[Tauri capabilities](https://v2.tauri.app/security/capabilities/) 明确区分窗口能力和自定义命令登记，因此采用 `AppManifest::commands` 与运行期来源校验；仅减少插件权限不足以保护应用自定义命令。[CSP 文档](https://v2.tauri.app/security/csp/) 对应脚本/IPC/样式策略，并通过原生 WebView 的 `securitypolicyviolation` 事件检查未授权脚本被拒绝。

[Tauri opener](https://v2.tauri.app/plugin/opener/) 的默认范围包含产品当前不需要的 scheme，改用显式 HTTP(S) 范围。[Rust Child 文档](https://doc.rust-lang.org/std/process/struct.Child.html) 说明 Drop 不自动等待子进程，故统一清理而非依赖对象析构。未实现 Windows Job Object，不宣称任意后代进程树都被约束；当前固定 CLI/broker 没有开放任意子工具执行。

Node 版本依据[发布周期](https://nodejs.org/en/about/previous-releases)，二进制摘要来自[官方校验清单](https://nodejs.org/dist/v24.22.1/SHASUMS256.txt)，随包许可来自[对应版本 LICENSE](https://raw.githubusercontent.com/nodejs/node/v24.22.1/LICENSE)。未新增 npm/Cargo 依赖或升级已有框架；打包二进制会增加安装体积。安装器使用既有 [Tauri NSIS 路径](https://v2.tauri.app/distribute/windows-installer/)。

## 交付边界与后续

干净 Windows VM/无 WebView2 机器尚未验收。当前 Windows Home 不提供 Windows Sandbox；独立目录、受限 PATH 和本机安装均不能冒称干净系统测试。浏览器仍受既有 Work 设置限制，未绕过；本轮原生 WebView 自动化单独记账。Windows 文件选择器、系统真实拒绝读取 ACL、强制 broker 崩溃注入、签名/更新、真实外部厂商账号也未完成本轮验收。

Vite 仍提示主包约 503.16 kB（gzip 166.48 kB）和静态/动态混合导入；这是明确保留的后续优化，未通过提高阈值隐藏。安装包尚未签名、发布；不称为“可正式分发”。P2 下一步补齐项目、运行与成果持久化，沿用本次确定的工具运行编号和失败语义。

启动、打包与原生验收见 [桌面 README](../../README.md)。新增运行环境变量为零。回退仅恢复本切片文件及构建配置，不重置既有工作、不迁移用户数据；恢复旧开发入口只作为定位问题的显式操作，发行版不提供隐藏源码回退。
