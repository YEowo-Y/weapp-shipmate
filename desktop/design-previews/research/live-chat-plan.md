# 真实文本对话最小闭环

日期：2026-10-17。用户要求继续推进；本轮把已连接的模型目录接到实际文本对话。保持现有原生 ES Modules、Node fetch 和共享对话组件，不新增依赖，不改变正式 Tauri 的能力声明。

## 范围与验收

- 默认仍为本地演示；只有用户显式选中已连接模型并发送才发起推理。首批 OpenAI、OpenRouter、Ollama，其他服务商继续明确为目录连接。
- 共用现有模型菜单、消息、停止、重试、阅读位置和页面生命周期。真实回复没有固定规则卡片、工具执行或审批示例。
- 真实请求只包含当前真实对话的纯文本，不能夹带固定示例、项目文件、密钥或其他会话；切换模式/模型清楚区分上下文，不自动迁移旧内容。
- 服务端复用 HttpOnly 会话与 CSRF，固定服务商目的地、校验模型属于连接目录、严格校验参数，限制请求/输出/时间/并发，不重试付费请求。
- 浏览器断开、停止、连接撤销、会话过期与服务关闭中止上游；迟到数据不得恢复旧运行。无正常完成帧的断流必须显示错误并保留部分输出。
- 采用 AI SDK 官方 UI Message Stream v1 文本子集（SSE start/text-start/text-delta/text-end/finish/error/abort/[DONE]），不另造消息传输协议；不声称实现完整 SDK。

## 分工与简化

后台负责提供商传输和现有 broker 路由；对话组件负责运行与显示；模型菜单负责可发现性及显式选择。保留既有演示控制器，不让真实模型驱动演示工具或审批。先写可失败的边界/生命周期测试，再扩展最小接口；不重写 UI、不引入第二个聊天框架。
