## 清理与修改顺序

1. 手机会话保留单一会话标题与导航入口；去除常驻审批浮层的重复信息，使用正常布局内紧凑审阅入口。保持所有审批/返回/焦点路径、短屏可发送、单滚动容器。
2. 设置中让连接状态和 API Key 入口靠近服务商标题；压缩重复说明，保留地址、能力边界与凭据说明。复用既有表单与对话框。
3. 模型选择器复用现有品牌图标，按服务商分组、显示选中标记，避免相同名称和ID重复。区分未连接、目录为空、连接异常、加载失败、部分目录；过滤无匹配时优先清空搜索，不以重载代替过滤恢复。保持请求取消、选择身份、忙碌禁切换。
4. 提升实际建议文字层级，保留演示标识与结构化结果，不把固定示例说成真实业务结果。
