配置服务器域名白名单

需你本人 · 工具不代点

小程序请求的后端域名必须先在后台登记，否则真机请求会被拦截。好消息：你代码里用到的域名我已经扫出来了，照着复制粘贴就行。

已完成 2 / 5 步

  1. 登录微信公众平台

    用注册时的邮箱 + 密码登录 mp.weixin.qq.com。

  2. 进入「开发设置」

    左侧菜单：开发管理 → 开发设置。下面这个按钮直接带你去：

    打开开发设置页
  3. 3

    把这个域名粘到「request 合法域名」

    船友已从你代码的 wx.request 里扫出这个域名

    https://api.shipmate.example

    找到「服务器域名」区块，在 request 合法域名 这一栏粘贴上面的值（必须 HTTPS + 已备案）：

    mp.weixin.qq.com · 开发管理 · 开发设置

    开发设置 › 服务器域名

    request 合法域名

    https://api.shipmate.example 粘到这里
  4. 4

    点「保存」提交

    填好后点右下角保存。这一步由你来点——船友不替你按保存。

    mp.weixin.qq.com · 开发设置
    点这个 保存
  5. 5

    回来勾「已完成」，船友帮你复检

    配置生效后回到这里勾完成，船友会重新扫一遍、确认这条阻断已清除。

卡住了？把后台截图拖进来

船友会在你的截图上标出"下一步点哪里"，但绝不替你点——提交永远是你按。
