# 对话操作连续性修复

日期：2026-10-16。继续现有 Codex / Claude 对齐，保留原生共享组件及渐变替代旋转圈的约定。仅处理当前预览的历史消息、输入草稿和会话切换，不迁移框架或接入模型。

## 已确认问题和验收

1. 点击编辑后立即同步发送按钮；输入区明确显示正在编辑，并可取消恢复原草稿。编辑期间切换编辑对象不覆盖原草稿备份。
2. 每条新回复绑定明确的源用户消息 ID，重新生成和失败重试沿用来源。旧记录只在没有来源 ID 时兼容按位置查找；显式来源无效时不能悄悄换成另一问题。
3. 切换会话清空本地运行/编辑关联；完整聊天将编辑关联随该会话草稿保存并恢复，其他会话不继承。运行期间禁用编辑，避免覆盖下一条草稿。
4. 复用已有 composer、按钮、图标和消息样式；不增加依赖、重复聊天状态机或新的后端协议。

## 步骤与证据

- 只读源码审查已用 VM 复现三个问题；真实浏览器复现编辑直接覆盖草稿且缺少取消入口。
- 修改前新增实际视图函数回归；修复后运行窄范围测试，再运行根 tests/lint 及预览显式 lint。
- 浏览器检查编辑/取消、会话往返、旧回复连续再生成、运行中禁止编辑、既有渐变、成功/停止状态；检查窄屏编辑条布局和控制台。
- 独立审查与截图记录；工作区已有未提交改动保留。风险 medium，共享 UI 和本地内存消息合同；不涉及生产权限、数据库或部署。
