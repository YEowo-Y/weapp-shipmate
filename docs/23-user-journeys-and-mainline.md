## 主线开发

工作流原先仅把含 `signal` 的规则标为条件要求，而上线清单同时识别 `match`。这导致同一规则在两处出现不同适用性提示，例如地理位置声明被工作流显示成无条件要求。

现在工作流对 `signal` 和非空 `match` 使用一致判断；接口和配置条件作为可读线索，其余匹配条件显示人工核对提示。此变化不会自动确认阶段，也不会把扫描结果当作官方审批。真实规则目录的三个主体类型逐项对照清单，回归先失败后通过；原生检查确认展示条件线索时不新增运行、报告或人工确认记录。
