本轮基于 `feat/ui-refresh-ocu-sync-20261025` 的 `5bd247211f163f713265fe9573a52c879d3294c3` 实施。开始前检查了 19 个本地分支和 14 个远端分支；产品分支均已包含在基线中，两个独立的 Dependabot 升级未纳入本轮。保留已有工作树和本地资料。

参考用户提供的 Codex、OpenCode 桌面截图、[OpenCode 固定版本](https://github.com/anomalyco/opencode/tree/432d870b02683d2e40e895ddc70d437189b25276) 与 [open-claude-ui](https://github.com/Caho1/open-claude-ui)。采用桌面设置的导航、阅读宽度和控件尺度；业务与存储继续使用本项目控制器。

## 信息结构与尺寸

- 偏好：外观与阅读、通知、快捷键。
- 应用：模型与连接、项目配置、数据与会话、隐私与权限、关于。
- 宽窗使用居中的 1048px 工作区内容，328px 导航分配、720px 内容上限，外围保留 24px 留白；较小桌面窗口收紧导航留白。
- 分区标题 16px / 22px，导航文字 14px / 20px，普通导航行至少 32px，设置组 8px 圆角、20px 内边距。
- 小于 800px 时在分类列表与详情间切换；搜索保持输入框可见，结果独立滚动。触控尺寸不小于 44px。
- 主题预览、即时保存与短暂保存反馈；不再保留常驻“完成”页脚。

## 行为与所有权

设置外层拥有唯一的主模态窗口、分类、搜索与焦点恢复。模型、项目、维护和会话数据继续使用原有控制器及状态；嵌入适配器提供 `element/open/close/canClose`，不复制存储或授权状态。旧独立弹窗适配器仍服务既有上下文入口及预览。

搜索同时匹配设置名称、分类和关键词，并定位实际控件。模型尚未连接时，模型目录搜索会定位到连接入口并提示前置条件。异步加载不会抢走用户后来移动的焦点。搜索结果显示期间保留业务 DOM，以便原有异步状态读取安全完成。

项目及维护设置继续显式保存。未保存草稿或写入操作会阻止离开，提供明确的放弃入口。会话导入保留 20 MiB 限制、追加副本、当前会话先保存和事务校验；项目备份沿用真实本机存储与容量状态。

新增发送快捷键选择：Enter 或 Ctrl / Command + Enter。Shift + Enter 始终换行，IME 组合输入与 Alt 不提交；提示实时更新。设置仅在存储成功后生效，损坏记录不会被静默覆盖。

隐私页展示当前会话真实的项目读取、摘要发送状态，并可撤销临时授权；不增加执行权限。关于页分别读取桌面运行版本、检查核心版本和项目规则版本，不虚构更新能力。原生能力清单仅新增读取应用版本。
