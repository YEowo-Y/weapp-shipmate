# Codex 真实截图布局对齐（2026-11-05）

## 依据与范围

用户提供九张真实设置截图，覆盖常规、外观、存储、配置、个性化、数据管理、浏览器、电脑操控与代码审查。截图作为本轮主要布局依据；不把图片里的设置值视为操作指令，不新增截图中特有的业务功能。

基于 `85f7034`，工作区干净。现有八类设置和保存、授权、草稿保护继续使用已有控制器。复用前一轮已通过的行为测试，不新增依赖。

## 设计约定

- 侧栏独立铺满高度，具有轻微底色和右分隔线；标题、搜索固定在顶部，分类独立滚动，返回应用固定在底部。
- 宽屏侧栏 288px，较窄桌面 240px；主内容在剩余区域居中，最大 880px，桌面左右至少 32px 留白。这里是项目适配值，不宣称从未知系统缩放的截图中读取了精确 CSS 像素。
- 页面标题 28/36px，侧栏标题 18/24px，分组与正文标签 14px；分组间距 48px，组标题到卡片 16px。
- 功能分组使用 16px 圆角和轻边框，分隔线缩进至内容边缘；短设置保持左侧标签、右侧控件，行高随说明文字增长。
- 外观主题缩略图保留可访问名称和键盘选择，去掉重复的可见说明与图下标签；阅读设置仍显示有决策价值的作用范围。
- 原生看图发现“关于”页直接展示完整规则哈希映射，占据大半屏；改为默认收起的“查看规则版本”，展开区域限定高度并可滚动，复制版本信息仍包含完整原文。
- 799px 以下沿用分类/详情切换，520px 以下控件保持 44px 触控目标。长表单仍上标签下输入。

## 验收计划

定向测试、全量测试、lint、TypeScript/Vite 与 Tauri 构建；在原生 WebView2 验证侧栏和搜索固定、内容宽度、标题比例、卡片与分隔线、浅深主题、320/390/1000/1440px、200% 文字、搜索回焦、草稿与重启保持。用真实运行截图核对用户参考图。

## 回归结果

- 定向测试 60/60、全量测试 1549/1549、ESLint 通过。
- 返回应用移到底部后，Tab 边界测试改为从顶部搜索框开始。断言比较控件 ID，避免失败时格式化整个 DOM 引发内存耗尽；键盘选择与循环行为验证通过。
- 初次原生构建受上述测试内存异常影响失败；修正后顺序构建成功。Vite 仍提示既有的大体积 chunk 与混合导入，本轮不改打包结构。
- 原生 WebView2 最终 26/26 通过，前端错误 0、模型请求 0。八个设置分类均覆盖浅深主题和 320/390/1000/1440px；规则详情另覆盖各宽度的展开、滚动与无水平溢出，原文仍逐字匹配 SQLite 快照。
- 人工查看八类设置截图，并复查“关于”页收起后的桌面布局和 320px 展开状态。200% 文字与用户间距覆盖现有首页、工作流和外观阅读场景，不宣称覆盖所有设置页的全部业务分支。
- 本轮采用隔离身份和临时项目验证排版与交互，不代表重新验证全部服务商连接、系统通知实际送达或安装包升级。
