# 设置内容与主侧栏评审

对照用户提供的 Codex「数据管理」「存储」「浏览器」「配置」截图，以及 5718a06 的 WebView2 实际页面。参考页把组标题放在卡片外，同一对象的说明与操作排在一起，复杂配置保留完整表单。此次沿用此前已验收的正文宽度、标题字号和窄窗分类切换。

| 页面或区域 | 原有体验 | 本轮处理 |
| --- | --- | --- |
| 主侧栏 | 工作台和当前会话同时高亮，三个工作区入口缺少可见组名 | 补上「工作区」，查看工作台或项目工作区时弱化最近会话的底色 |
| 设置侧栏 | 原「应用」混合项目操作和应用信息 | 模型、项目和数据归入「工作区」，隐私与关于留在「应用」。搜索固定顶部，返回固定底部 |
| 通知 | 开关、权限说明、状态、测试操作相互分散 | 按「通知偏好」「状态与测试」归组，权限说明贴近开关 |
| 项目配置 | 保存与放弃分行，备份与运行记录入口之间夹着状态和重载 | 同一行处理保存与放弃，将两个跳转入口集中放在表单后 |
| 数据与会话 | 导出和导入各占一张卡，主要操作堆叠在说明下方 | 两行共享「会话备份」卡片。宽窗操作靠右，窄窗按阅读顺序堆叠，导入确认紧邻选文件 |
| 关于 | 复制版本占据标题前的一行，空反馈留白 | 版本组标题与复制操作同行，复制反馈就近出现 |
| 外观、快捷键、隐私 | 已使用分组卡和行内控件 | 保留当前结构并纳入浅深色及窄窗回归 |
| 模型与连接 | 服务商选择与凭据编辑需要同时可见，窄窗已有纵向布局 | 保留服务商和编辑区的主从关系，纳入同一组回归 |
