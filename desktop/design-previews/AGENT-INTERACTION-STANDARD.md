# Agent 交互标准

本规范约束设计预览的主工作台与完整聊天页。交互对齐成熟桌面 Agent 的常用模式，保留上线船友的阶段导航、规则依据和逐文件审批。默认使用本地确定性示例，显式选择已连接模型后可进行真实文本聊天；添加菜单可主动运行本机上线清单工具，不写入项目文件。

## 当前补充（2026-10-17）

以下历史记录按日期保留。当前设置提供真实模型目录认证 broker，聊天可显式选择 OpenAI、Anthropic、Google、OpenRouter、Ollama。凭据仅存本机服务会话内存，不存前端草稿。目录成功不等于该模型推理已验证，详见 [最新文本流记录](research/anthropic-google-chat-report.md)。

- 真实文本使用 AI SDK UI Message Stream v1 子集，保留状态机、消息与安全 Markdown；不夹带固定演示记录、引用文件或其他会话文本，不生成假的工具或审批结果。
- 编辑遵从当前显式选择，同模型才能复用原历史分支；重试与再生固定原请求，并把当前模型和按钮说明同步到实际目标。
- 停止、离页、切会话与断开连接中止请求并忽略迟到事件；异常断流/截断与成功分开，不自动重试可能计费的请求。
- “生成上线清单”独立于模型选择：三个条件须明确填写，复用本机 `runGuide`。工具运行状态采用 AI SDK UI Message Stream v1 工具事件；完整终态及结果校验通过后才展示适用/自查两类清单，不生成虚假的模型决策、审批或合规结论。保留草稿与模型，原参数重试，结果不自动加入模型历史。见 [本机工具合同与验证](research/local-guide-report.md)。
- 清单成果提供完整 Markdown 复制、Markdown/原始 JSON 下载与字面搜索。搜索只控制显示，复制和下载总是使用完整已校验结果；动作处再次核对已完成状态与输入/结果。搜索在中文组合输入结束后应用，清空恢复搜索前的阶段展开状态；会话视图按消息保存搜索，更新消息保留搜索节点与焦点。下载只提示“已发起”，重复下载复用有界 Blob URL，会话切换、销毁与离页清理资源。见 [成果操作验证](research/guide-artifact-report.md)。

- 页面与命令面板共用功能目录，阶段来自同一份 `STAGES`；全部 8 个阶段可搜索发现。
- 设置往返保留允许的来源页面、阶段及首次引导选择；拒绝外部/未知目标。设置历史切换只在焦点将随旧面板隐藏时恢复到新栏目，不抢搜索或外部焦点。
- 完整对话和工作台离开时统一清理运行；页面缓存只保留可恢复的视图，不恢复旧流式计时器。故障演示在忙碌时明确拒绝，提交成功后才显示启动反馈。
- 完整审阅携带来源，阶段→拒因/健康→后续工具有明确返回入口。各页局部草稿仍不保证跨页面导航持久化。
- 正式桌面报告清晰区分本次结果和上次成功结果；失败保留后者，目录/主体变化后使其失效。复制操作独立反馈，失败可重试。

本轮源证据、完整功能矩阵及验证边界见 [全产品评审](research/product-wide-review-report.md)。浏览器视觉与原生系统交互未在本轮验收。

## 统一交互合同

| 部分 | 标准 |
| --- | --- |
| 消息 | 用户消息轻背景；Agent 正文以阅读为主，工具过程、依据和动作分层；复制与重新生成在消息附近 |
| 流式 | 准备 → 输出 → 完成；停止/错误是独立终态；取消后保留部分内容，旧任务不得继续追加 |
| 输入 | 空白禁止发送；Enter 发送，Shift+Enter 换行；中文组合输入不触发发送；自动增高有上限 |
| 生成中 | 同一主按钮切换为停止；输入框继续可编辑；草稿不会被完成事件清空 |
| 滚动 | 接近底部才跟随；上翻阅读时不夺取位置；提供“回到最新” |
| 错误 | 在对应消息解释失败并给重试；重试沿用输入，避免重复用户消息；演示故障与真实连接失败分清 |
| 工具 | 公开任务摘要，不展示伪造思维链；成功过程默认折叠，失败保持可见 |
| 审批 | 待审批/已批准/已拒绝/已失效一致；批准与停止生成分离；真实写入和重扫留给正式适配器 |
| 会话 | 切换真正更换内容；草稿隔离；编辑重发保留历史版本或以明确分支呈现 |
| 菜单 | @ 与 / 根据输入过滤；方向键选择、Enter 确认、Escape 收起；弹层之间互斥 |
| 对话框 | 原生 modal，明确标题与关闭；Tab 留在内部，关闭后回触发器；长内容内部滚动 |
| 命令面板 | Ctrl/⌘K 原位打开，搜索、空态、键盘激活、Escape 返回当前上下文 |
| 动效 | 状态变化克制；无逐字闪烁或持续装饰；尊重 prefers-reduced-motion |
| 信任 | 规则依据与 AI 建议分区；无真实 ruleId 验证不授予生产意义的“已核验”；原型标明示例 |

## 历史消息与草稿（2026-10-16）

- 编辑旧消息时，输入框显示“正在编辑消息”和取消入口，发送按钮即时更新。取消或 Esc 恢复进入编辑前的草稿；切换编辑对象保留最初草稿。补全菜单或输入法占用 Esc 时，不取消编辑。
- 发送编辑内容会追加新版本并保留旧消息，随后恢复原草稿。当前没有版本树导航，不把追加消息声称为完整的分支管理。
- 生成期间可以继续写草稿，但不能点击历史消息的编辑、重新生成或重试操作覆盖当前状态。
- 新回复保存 `sourceUserId`；重新生成和重试使用该来源。只有没有来源字段的旧消息兼容按前序位置查找，显式失效的来源不能回退到其他问题。
- `mountConversation.submit()` 消费输入框内容；`submit({ input })` 是独立的页面动作，保留输入框草稿及待编辑状态。三个页面适配器不再分别备份/恢复草稿。
- `getDraftState()` / `setDraft(text, edit)` 用于会话级草稿恢复；`replaceMessages()` 清除旧运行、编辑关联及状态播报。编辑来源必须属于当前会话。

实现、测试和视觉验收限制见 [连续性修复记录](research/conversation-continuity-report.md)。

## 模型设置与选择（2026-10-16）

- 模型菜单只选择已实际可用的执行来源；当前是本地演示。删除不影响执行的“均衡 / 深入”，不把推理强度或权限模式混入模型选择。
- 服务商设置与对话选择分开：服务商搜索、配置详情、凭据、模型列表各有明确职责。未连接模型不能因为添加草稿而变成可用。
- 预览密钥仅在原生弹窗的临时 DOM 输入中，关闭/切换/离开时清空；不保存、不发送。地址检查是格式校验，不能显示连接成功。
- 工具摘要优先，原始 JSON 二级折叠；规则依据可展开，审批独立。状态更新保留已有折叠区状态与阅读焦点。
- 调研证据、302 项测试与浏览器限制见 [本轮报告](research/model-settings-alignment-report.md)。

## 正式桌面接入边界

浏览器层只依赖统一事件与状态，不直接解析 Claude NDJSON 或 Codex JSONL。生产集成还需要真实 provider 适配器、鉴权、网络重连、工具执行与取消、文件版本检查、持久会话、checkpoint 及重扫结果。设计预览不声称这些能力已交付。
