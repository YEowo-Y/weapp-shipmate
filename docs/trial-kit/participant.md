# 参与者一页卡 · 上线船友练习

这是一份试用练习，不是真实小程序业务。**请勿提交微信审核。** 不需要微信AppID、AppSecret、模型密钥、证照或付费账号，也不需要在微信开发者工具里运行它。你可以随时停止。

请先按提供的说明取得桌面候选；若无法下载、安装被拦截或不愿继续，请直接告诉主持人，不必关闭电脑的安全保护。

1. **选择练习目录。** 把收到的`practice-miniapp`文件夹复制到自己方便找到的位置。在上线船友中打开这个目录，不要选择整个电脑或真实业务目录。
2. **做一次预检。** 找到一项发现，读出你认为下一步要做的事及依据。它是修改代码、后台配置、准备材料还是人工确认？不确定也可以直接说。
3. **看看上线导航。** 练习没有给你的业务事实，保留“尚未确定/不知道”。不要为了完成表格猜答案。请用自己的话说出下一步，以及你为什么这样理解。
4. **看看空白拒因页面。** 打开拒因查询，暂时不输入内容，说明你认为现在有没有查询结果；这里没有真实拒审信，请勿编造。
5. **导出并恢复练习项目。** 导出项目备份，在项目管理中预览后追加恢复，并重新选择这个练习目录。保留原练习项目，不需要删除或归档。说明恢复的报告是不是刚刚重新检查的结果。
6. **重开确认。** 关闭再打开工具，找到练习记录。告诉主持人哪一步难找、哪个词不清楚、是否需要帮助。

这里的定位API只是不可执行的静态练习信号，打开页面不会获取位置。预检命中代表扫描器看见了代码线索，不代表你已授权定位或已满足官方要求。删除不需要的示例也是合理下一步；本练习不要求修改代码或使用受限修复候选，不必确认并不存在的业务需要。项目备份不包含源码或修复日志。

主持人只记录匿名编号、操作结果和你愿意提供的反馈。不要在反馈中粘贴真实源码、账号、密钥或个人信息。结束时由你决定是否保留练习目录和备份。
