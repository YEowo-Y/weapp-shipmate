# 模型连接页面：改造与浏览器验收计划

2026-10-17。用户明确要求实际优化并补齐浏览器自动化。本轮采用直接实施与有界原生子代理；沿用原生组件、现有目录代理、OAuth PKCE 和统一品牌图标，不安装新的产品框架。

## 已观察问题

真实浏览器基线：服务未运行导致首次连接失败，已启动回环预览服务。设置页首屏有一整段边界说明，详情仅服务地址和同级按钮，大面积空白；服务商列表无法辨别连接状态。代码发现密钥输入512与服务端4096上限不一致，断开也显示读取目录，目录搜索无命中计数，刷新重建丢失目录滚动位置，OAuth刷新页面后等待链接丢失。

## 最小范围与验收

1. 详情按身份/能力、连接方式、模型目录组织；缩短首屏说明，把凭据生命周期和产品订阅差异放到就近说明。列表展示真实状态；成功提供返回对话入口，Anthropic/Google只标目录能力。
2. API Key弹窗复用原生dialog，明确目标、获取密钥链接、显示/隐藏、取消、Enter提交；4096限制与后端一致，空白不提交，关闭/提交清空。连接/刷新/断开/授权分别显示实际动作，执行中使用文字渐变及减弱动效回退。
3. 目录提供匹配计数、零匹配清除、空目录说明、刷新重试；刷新保留已有数据和滚动/搜索/焦点。OAuth等待但缺少本页链接时给可执行恢复路径，不持久化授权URL或密钥。
4. 真实浏览器覆盖默认服务、API Key弹窗和键盘、搜索、OAuth开始/取消/恢复、成功/失败/空目录/断开、深浅主题、320/390/768/1440宽度及溢出。浏览器内建工具已可用；无需叠加新的自动化框架。
5. 没有用户凭据，因此供应商成功/错误/限流等用独立的、显著标明测试的回环fixture服务注入上游响应；实际HTML/JS与认证代理照常执行。生产5501不加入mock开关。不会将测试上游冒充真实供应商验证，也不调用付费模型。

## 所有权与简化

研究代理只写sources；实现代理负责settings.js与对应测试；主代理负责settings.html/settings.css、浏览器与整合；验证环境代理负责独立fixture脚本与其测试。所有人保留既有脏工作区，不回退他人改动。不改模型推理协议或引入订阅OAuth。

删除重复说明，复用现有按钮/dialog/状态与目录数据，不建设第二套设置运行时。CSS修改前后以真实截图和DOM尺寸检验；采用浏览器对照评价，记录verdict JSON，不声称像素克隆或获奖认证。

## 质量配置与完成条件

浏览器与独立评审触发的必要范围扩展：服务端刷新保留旧目录、fixture独立Cookie、共享原生dialog首尾Tab循环。均先复现后修复，已补单测和浏览器复验；最终证据见model-connection-polish-acceptance.md及.omx/artifacts/model-connection-polish/browser-acceptance.json。

风险high：认证UI与异步生命周期。质量配置来自package.json/desktop/package.json和既有CI validate-rules（Windows/Linux Node20/22/24）；本机Node24。既有598测试为基线；改动先用回归或浏览器复现，再运行定向测试、全量npm test、根lint、显式desktop JS lint、desktop TS/Vite build、静态资源、diffcheck、独立只读评审。

DQ-00/01/02/04/05/07/10适用；不改依赖或持久数据，无迁移。浏览器使用当前支持的CUA/Playwright locator接口，响应式viewport与开发日志检查；若工具缺失先安全补齐，不绕过安全拦截。真实供应商账号/付费推理、原生Tauri和跨平台CI非本轮验收声明范围。仅可声明本地UI验收，不能声明release-ready。恢复只撤回本轮增量并停止独立测试服务，不影响规则或已有用户文件。
