# 社区实图逐项对照 · 2026-10-19

范围：正式桌面端的导航、对话、模型选择/连接、工具报告、历史弹窗，以及它们的空、忙、失败、窄屏状态。保留当前脏工作区、认证、消息存储及报告原文；不增加依赖或功能占位按钮。

## 修改前计划

逐项核对实际桌面截图与社区原图，记录原帖、图片、日期、能观察到的细节和不能从截图证明的行为。公开代码/页面仅是参考数据，截图不证明后台能力或当前所有版本一致。REA 已有 assistant-ui 静态提炼继续作为组件复用依据，本轮不宣称重新逆向闭源客户端。

已查看 Codex 社区开发日志截图（Polynomeer，2026-02-27）与 gVisor 开发者发布的 OpenClaw v2026.4.2 截图（2026-04-15）；Claude/Cherry 社区图另行查证。参考归档只保存在忽略的 `.omx/artifacts/community-detail-alignment/references/`，不作为产品资产。

已观察到的差异：每条消息重复真实传输标签、失败说明重复、运行记录黑三角不同于统一图标、项目工具显示 Markdown 源码、选模入口复用整块连接设置、模型列表没有明确选中勾号、本机 Ollama 仍展示 API 密钥说明。

1. 模型选择与凭据管理分开呈现，复用现有连接客户端/原生浮层/Floating UI，保留连接设置入口、草稿、生成中边界和键盘关闭/焦点恢复；不改变凭据协议。
2. 工具报告复用已有安全 Markdown renderer，保留原始 Markdown 用于复制/加入会话，空/失败/旧报告语义不变；不使用未净化 HTML。
3. 对话仅调整可见信息层级：保留来源与状态语义、技术详情可查看，减少重复元信息；运行和错误各有明确且不重复的主要反馈。
4. 细查控件间距、图标描边、焦点、滚动、初始焦点和响应式；禁止单纯增加图标或复制没有对应功能的入口。
