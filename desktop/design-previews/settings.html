凭据与使用说明

凭据仅保存在本机服务内存，重启服务或闲置 60 分钟后失效。同步目录不发起模型推理；在对话中发送消息可能产生 API 费用。

管理归档

备份包含哪些内容？

备份仅包含当前工作区的会话记录，不包含模型密钥、登录授权或项目文件。消息中手动输入的内容会随记录导出，请妥善保管。

支持上线船友的 JSON 会话备份。导入前会校验格式并显示数量；历史任务不会自动重跑，旧审批需要重新确认。

记录保存在当前浏览器或桌面设备。本页不提供云端同步；换设备时可手动导出并追加导入。
