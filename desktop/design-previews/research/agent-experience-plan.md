# Agent 对话体验提升计划

2026-10-17。用户要求按前沿开源 Agent 产品持续打磨，对标 Codex、Claude、OpenClaw 的前端与交互；沿用此前明确的代码与自动化验证范围。真实浏览器被设置禁用，视觉门禁记录为 BLOCKED，不借旧截图声称当前视觉完成。

## 改造范围

1. 标准正文输出：采用成熟 Markdown 解析库而不是正则自造语法。保留原生 ESM 预览和共享消息运行时；只新增确实用于正文的固定版本开源资源，记录官方来源、许可证和完整性。支持标题、列表、引用、行内代码、代码块、表格与链接。未经授权的 HTML/脚本不能成为活动 DOM；外部图片不自动加载。代码与表格可独立滚动，复制代码有明确反馈。
2. 流式连续性：保留未变化的内容块、代码滚动与焦点；完成/停止不能清空已输出内容。复制原始消息仍来自原始正文，避免从视图反向拼接。现有工具、审批与执行事件协议保持不变。
3. 细节修复：窄栏模型选择保留可见名称；已有消息状态更新不重播整条入场；复制在原控件反馈结果，失败可重试，迟到回调不污染另一会话。
4. 视觉自检：明确正文/次要信息/工具记录的层级，统一标题及段落节奏；代码与表格使用已有中性色、边界、字号及图标，保留执行文字 shimmer、减少动效与强制颜色支持。小屏保证恢复路径、可见标签、触控目标和长内容不撑宽页面。原创性来自小程序上线工作的阶段、依据和审阅路径，不仿造品牌或虚构产品能力。

## 顺序与保护

先完成官方 API/许可确认与接入点映射；已有基线 339 项通过。新行为先补可失败回归，再最小实施；并行任务按文件分工。最后独立复核、安全输入/流式切片/阅读位置/复制失败与会话切换验证，完整 Node 测试、lint、桌面 build、HTML/CSS/ESM/HTTP 检查。桌面 build 不等同独立预览已集成到 Tauri。

本轮不增加真实模型、密钥存储、后端权限、多 Agent、图表引擎或可执行模型代码。Markdown支持范围和未验证项在交付报告中逐项说明。
