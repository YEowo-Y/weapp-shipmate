# 11 · Outreach 极简执行计划（Go/No-Go 最后一勾）

> 目标只有一句话：**找 5 个目标用户读 `guide` 输出，≥3 人能复述"我下一步要做什么"即通过。**
> 这是 docs/04 Go/No-Go 五勾中唯一未完成项。已裁决：不卡 v0.1.0 预览发布——预览即 outreach 载体（有可安装的包，邀人试比发私仓链接容易一个量级）。

## 找谁（5 人画像，按易触达排序）

1. 正在或曾经**独立上线过微信小程序**的个人开发者（最贴目标用户）
2. 写过小程序但**卡在过审/备案/类目**环节的开发者（痛点在体）
3. 会写代码但**从未碰过小程序生态**的 web 开发者（测导航对新手的可读性）
4. 用 uni-app / Taro 的跨端开发者（测框架覆盖的说服力）
5. 任何愿意花 10 分钟的技术朋友（对照组：完全无上下文能否读懂）

渠道：个人开发者社群（微信群/即刻/V2EX/掘金）、朋友直邀。话术一句话：「我做了个小程序上线陪跑工具，花 10 分钟读一份它生成的清单，告诉我你下一步会做什么。」

## 给什么（统一物料，二选一）

- **A（零安装）**：预先跑好的 `guide --subject personal --sensitive --domain` Markdown 输出 + `check` 真实项目报告样例，直接发文本。
- **B（有包之后）**：`npm install -g github:YEowo-Y/weapp-shipmate` 一行命令 + 让对方跑自己的项目。

任务指令只一句：**「读完后，用你自己的话说：你的下一步是做什么？」** 不解释、不引导、不补充上下文（测的就是导航自解释能力）。

## 判定与记录

| 记录字段 | 说明 |
|---|---|
| 对象编号/画像 | 上面 1-5 哪类 |
| 给的物料 | A 或 B |
| 复述原话 | 逐字记，不润色 |
| 判定 | ✅ 能说清下一步 / ❌ 说不清 / ⚠️ 说对了方向但步骤错 |
| 卡点 | 哪个词/哪段没看懂（喂给规则文案迭代） |

结果记录在本文件末尾追加（一人一行）；≥3/5 ✅ 即回填 docs/04 的最后一勾。
❌ 集中出现的卡点 → 开 issue 逐条修文案（`why` 字段与 guide 渲染语序是主要嫌疑面）。
